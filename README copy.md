<h3>##Organização Financeira Pessoal</h3>

Análise e Desenvolvimento de Sistemas - PUC Minas

Desenvolvimento de aplicação web front-end

2º semestre/2026


<p>
O projeto Contaí tem como objetivo facilitar a organização financeira pessoal por meio de uma aplicação web que reúne, em um único ambiente, informações como receitas, despesas, saldos, metas, limites de gastos e compromissos financeiros futuros. A proposta é oferecer ao usuário uma visão mais clara da sua situação financeira, reduzindo a necessidade de consultar diferentes planilhas, aplicativos ou anotações. Voltado para pessoas físicas, o sistema busca apoiar o acompanhamento e o planejamento das finanças de forma simples, organizada e acessível, seguindo a ideia de que cada valor conta.
</p>
